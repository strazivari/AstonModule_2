## О проекте

Консольное Java-приложение считывает студентов и списки их книг из текстового файла, создаёт объекты `Student` и `Book`, а затем обрабатывает общую коллекцию книг **одной цепочкой Stream API**. Программа выводит сведения о студентах и год издания первой подходящей книги либо сообщает, что такая книга не найдена.

Реализация основана на исходных файлах проекта `AstonModule_2`; примеры ниже соответствуют данным, находящимся в приложенном архиве.

## Используемые технологии

- **Java 25** — версия исходного и целевого байт-кода, указанная в `pom.xml`.
- **Maven** — сборка и запуск тестов.
- **Java Collections Framework, Stream API, Optional** — хранение и обработка объектов.

- **JUnit Jupiter 6.1.3** — модульные и интеграционные тесты.

## Модель данных

### `Book`

Книга содержит `title` (название), `pages` (количество страниц) и `year` (год издания). Конструктор проверяет непустое название, положительное число страниц и положительный год. Поля объявлены `final`; класс также объявлен `final`.

В `Book` переопределены `equals()` и `hashCode()`: книги считаются одинаковыми, **только если совпадают название, число страниц и год**. Это необходимо для корректной работы `distinct()`. Для сортировки используется отдельный `Comparator` по количеству страниц.

### `Student`

Студент содержит имя и обязательное поле `List<Book> books`. Конструктор отклоняет пустое имя, `null` вместо списка и списки, содержащие **менее пяти книг**. Коллекция сохраняется через `List.copyOf(books)`, поэтому её нельзя изменить через внешнюю ссылку. Метод `toString()` переопределён для вывода студента вместе с книгами.

## Файл со студентами и механизм чтения

Основные входные данные хранятся в `src/main/resources/students`. В текущем архиве файл содержит **трёх студентов — Vlad, Anna и Oleg, у каждого по пять книг**. Используются названия книг по программированию.

Формат одной строки:

```text
Имя|Название книги,Страницы,Год;Название книги,Страницы,Год;...
```

Пример из основного файла:

```text
Vlad|Java Basics,320,2021;Clean Code,464,2008;Algorithms,280,1998;Spring Guide,410,2022;Database Fundamentals,350,2019
```

Здесь `|` отделяет имя от книг, `;` разделяет книги, `,` — поля каждой книги. Названия, содержащие эти символы, текущий формат не поддерживает.

`StudentFileReader.readStudents(Path)`:

1. Считывает строки командой `Files.readAllLines(path, StandardCharsets.UTF_8)`.
2. Пропускает пустые строки и строки из пробелов.
3. Разбивает строку на имя студента и сведения о книгах.
4. Для каждой книги преобразует количество страниц и год в `int`, создаёт `Book`.
5. Создаёт `Student` и добавляет его в `List<Student>`.
6. Возвращает заполненный список; при ошибке формата или невалидных значениях выбрасывает исключение.

Таким образом, основная программа **не создаёт список студентов вручную**: коллекция заполняется из текстового файла.

## Обработка в одной цепочке Stream API

В `Main.processStudents(List<Student>)` используется следующая последовательность:

```java
students.stream()
        .peek(System.out::println)
        .map(Student::getBooks)
        .flatMap(List::stream)
        .sorted(Comparator.comparingInt(Book::getPages))
        .distinct()
        .filter(book -> book.getYear() > 2000)
        .limit(3)
        .map(Book::getYear)
        .findFirst()
        .ifPresentOrElse(
                year -> System.out.println("Год: " + year),
                () -> System.out.println("Книга не найдена")
        );
```

| Операция | Назначение |
|---|---|
| `stream()` | Создаёт поток студентов. |
| `peek(System.out::println)` | Выводит обработанных студентов через переопределённый `toString()`. |
| `map(Student::getBooks)` | Получает `List<Book>` для каждого студента. |
| `flatMap(List::stream)` | Преобразует списки в единый поток объектов `Book`. |
| `sorted(Comparator.comparingInt(Book::getPages))` | Сортирует книги по возрастанию страниц. |
| `distinct()` | Исключает книги, равные по `equals()` и `hashCode()`. |
| `filter(book -> book.getYear() > 2000)` | Оставляет издания начиная с 2001 года. |
| `limit(3)` | Ограничивает поток максимум тремя элементами. |
| `map(Book::getYear)` | Получает годы издания книг. |
| `findFirst()` | Выполняет короткое замыкание и возвращает `Optional<Integer>`. |
| `ifPresentOrElse(...)` | Печатает год либо сообщение об отсутствии книги. |

**Один Stream без промежуточных переменных:** вся обработка в методе `processStudents` записана единой цепочкой без объявления промежуточных локальных переменных. `List::stream` внутри `flatMap` — часть этой цепочки. Переменные, используемые отдельно при чтении файла, не относятся к этому требованию.

**Особенности:** `peek()` здесь применяется для демонстрационного вывода студентов; для обязательных побочных эффектов в общем случае он не предназначен. Поскольку в этой последовательной цепочке присутствует `sorted()`, все входные книги должны быть обработаны до выбора первого года. `limit(3)` присутствует по условию задания, хотя следующий `findFirst()` возвращает только первый из оставшихся годов.

## Как запустить

**Требования:** JDK 25 и Maven. Команды выполняются **из корневой папки проекта**, в которой находится `pom.xml`: путь к исходному файлу в `Main` задан относительно рабочего каталога.

Проверка версии Java и Maven:

```bash
java -version
mvn -version
```

Сборка и тестирование:

```bash
mvn clean test
```

Запуск программы после сборки (Windows PowerShell / CMD):

```powershell
java -cp target\classes org.example.Main
```

Также можно открыть проект как Maven-проект в **IntelliJ IDEA**, дождаться загрузки зависимостей и запустить `org.example.Main` либо цель Maven `test`.

## Тестирование

Тесты находятся в `src/test/java/org/example/`. В проекте объявлено **19 тестовых методов**:

| Класс тестов | Количество | Проверяемое поведение |
|---|---:|---|
| `BookTest` | 5 | Создание книги, равенство, хеш-код, удаление дублей, валидация. |
| `StudentTest` | 5 | Минимум пять книг, валидация, неизменяемость списка, `toString()`. |
| `StudentFileReaderTest` | 7 | Чтение корректного файла, пустые строки, ошибки формата, чисел, числа книг, отсутствие файла. |
| `MainTest` | 2 | Результат обработки Stream и сообщение при отсутствии подходящих книг. |

`src/test/resources/studentsTest` содержит постоянный тестовый набор. `StudentFileReaderTest` также применяет `@TempDir`, чтобы создавать временные файлы с ошибочными данными, не изменяя основной ресурс. В `MainTest` вывод консоли проверяется через временное перенаправление `System.out`.

Для запуска всех проверок:

```bash
mvn test
```

Успешное завершение Maven отображается как `BUILD SUCCESS`. **Фактический прогон всех JUnit-тестов на JDK 25 необходимо выполнить в локальной среде** перед сдачей работы.
